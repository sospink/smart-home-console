# 合同软件交付台账

依据：[原始合同](../../项目资料/合同与采购/步入式实训台0610(1).docx)（17 条）和[硬件采购清单](../../项目资料/合同与采购/副本步入式实训硬件0610修改版2(1).xlsx)。本台账只记录当前可证明状态，不以页面、Mock 或计划冒充硬件验收。

## 状态口径

- **未开始**：没有可用实现；
- **平台闭环**：UI → 正式 API → EdgeCore → 持久化/适配器边界可执行，但尚未覆盖目标硬件；
- **硬件待验证**：软件边界存在，指定 SKU/固件或现场条件没有证据；
- **硬件已验证**：指定 SKU、固件和动作有可复现真机证据；
- **阻塞**：采购参数或接口使合同要求无法由当前方案证明；
- **已验收**：项目方在目标环境完成验收并冻结证据。

## 总体软件解释

合同描述的是统一智慧家居控制系统，不是两套互不相关的大屏应用。每套实训台由主屏 EdgeCore 提供唯一权威状态，主屏和副屏分别承担全局控制与高频快捷控制并实时同步；两套实训台各自独立部署。

合同没有开课、学生/小组、题目、评分、成绩或故障注入要求。正式产品只保留智慧家居控制和为接入、诊断、审计、备份所需的受限工程管理。

## 当前真机证据

- 2026-07-27：本台 `DMWG03LM / lumi.gateway.mcn001 / 1.0.8_0013` 与 `xiaomi.light.btlm2` 通过 HA 官方 Xiaomi Home 接入；
- 已验证主副屏开关、55% 亮度、2700–5700 K 色温、五项灯效与 HA 外部改值回传；
- 该路线依赖 HA 与小米云，不是 DMWG03LM 本地 API；
- 证据不覆盖第二套实训台、其余 SKU、断公网、采购屏 Kiosk、RS-485、门锁、窗帘、传感器、R11 或语音。

## 验收前必须补齐

1. 最新 APK 在采购主副屏完成安装、升级、重启、Kiosk、网络切换和真实控制回归；
2. 第二套实训台建立独立控制域并证明不串台；
3. 所有采购 SKU 建立 model → entity → capability → 实机结果清单；
4. 验证断公网的实际行为，不得将 HA 官方 Xiaomi Home 云链路称为本地控制；
5. 对 RS-485、合同副屏分辨率、门锁容量和 R11 接口缺口形成书面处置；
6. 获得正式发布密钥后签名 Release APK，再进行安装、升级与回滚验证。
