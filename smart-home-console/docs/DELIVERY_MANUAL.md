# 安装、工程管理与运维手册

## 1. 系统组成

每套实训台安装同一个 APK：

- 主屏选择 **PRIMARY**，运行本机 EdgeCore、Room 数据库和 `/primary`；
- 副屏选择 **SECONDARY**，配对主屏后加载 `/secondary`；
- 工程管理 `/admin` 由主屏或受控局域网工程终端打开；
- 两套实训台必须分别配置，不能共用终端令牌、数据库或 `controlDomainId`。

当前本台设备控制路径是 `EdgeCore → Home Assistant → 官方 Xiaomi Home → 小米云 → DMWG03LM → 灯`，不是网关本地直连。

## 2. 首次安装

1. 将主屏和副屏接入同一个受信 VLAN/专用 Wi-Fi；禁止接入访客网络。
2. 安装同版本、同签名 APK。主屏选择 PRIMARY，副屏选择 SECONDARY。
3. 将 APK 设置为默认 HOME/Kiosk；普通应用仅接收开机广播不足以保证 Android 10+ 自动显示界面。
4. 主屏首次设置 6–12 位工程 PIN，并按学校安全制度离线保管。
5. 在主屏工程管理的“网关配置”写入 HA 地址、长期令牌、网关状态实体和设备实体。Token 只进入 Android Keystore。
6. 点击“网关与灯联检”，必须同时证明 HA 可达、目标实体存在且状态可读。
7. 在“终端管理”读取六位一次性配对码，在副屏完成配对。
8. 确认两屏顶部为“正式运行”，控制同一设备后另一屏收到权威状态；测试夹具不得用于现场验收。

使用 ADB 安装 Kiosk：

```bash
ADB=/path/to/adb ./scripts/install-android-kiosk.sh
```

## 3. 日常操作

### 主屏

- 首页用于查看连接、在线设备、运行负载、告警和常用场景；
- 设备页按房间筛选并进入单设备详情；
- 控制后先显示同步中，只有 EdgeCore 确认才显示成功；
- 离线缓存只用于查看最后可信状态，不能控制。

### 副屏

- 用于高频场景、灯光、窗帘、音乐和告警；
- 显示的灯光/窗帘/音乐对象由后台“副屏槽位”映射，不按商品名自动猜测；
- 副屏浏览主屏界面时仍以副屏终端身份操作，审计来源不会变成主屏。

### 界面切换

顶栏终端菜单可以在主屏、副屏和管理界面间切换。切换只改变当前视图，不改变 APK 的 PRIMARY/SECONDARY 物理角色。离开管理界面时系统会注销管理会话。

## 4. 工程管理九个模块

| 模块       | 什么时候使用                                      | 关键注意事项                                         |
| ---------- | ------------------------------------------------- | ---------------------------------------------------- |
| 运行总览   | 交班、检查告警/离线/在途操作、恢复安全基线        | 先运行检查，再决定是否复位；离线项必须人工核对       |
| 房间与设备 | 改名称、房间、显示顺序、收藏、副屏槽位和实体映射  | 控件由 capability 决定；不要按商品名伪造能力         |
| 场景编排   | 配置回家、离家、夜间、观影及现场自定义场景        | 每个动作必须引用存在且可写的 capability              |
| 自动联动   | 配置传感器条件、动作和冷却                        | 试运行会真实下发，现场操作前确认目标设备安全         |
| 告警中心   | 查看、确认和恢复告警                              | “确认”不是“恢复”；异常仍存在时不能强制清除           |
| 网关配置   | 写入 HA/网关凭据引用、目标实体并联检              | 每套 EdgeCore 只保留本台唯一网关配置                 |
| 终端管理   | 查看物理屏/Web 调试状态、生成配对码、撤销副屏     | 撤销后旧 Token/ticket/WebSocket 全失效，必须重新配对 |
| 配置备份   | 导出/恢复配置、数据库快照、容量健康、签名 UI 更新 | 配置 JSON 与 SQLite 快照用途不同；凭据不进入备份     |
| 审计日志   | 追溯控制、场景、告警、配置、安全与运维结果        | 使用服务端分页/筛选导出，不直接改数据库              |

窄屏后台顶部菜单可横向滚动；表单和操作按钮应自动换行。如果输入框或按钮重叠，先记录视口与 APK 版本，不要缩放 WebView 规避。

## 5. 设备安全复位与运行交接

1. 在“运行总览”保存本台复位策略：灯光/音乐/开关可关闭或保持，窗帘可关闭/打开/保持，联动抑制 3–30 秒。
2. 打开“复位检查”查看实时影响清单。严重告警、在途命令/场景会阻止执行。
3. 纳入策略的设备逐台经过正式命令状态机；离线设备转为人工核对，门锁和只读安防不会被操作。
4. 联动抑制持续到最后一台动作结束后再保留完整策略窗口，避免延迟回报把设备反向改回。
5. 打开“运行检查”，处理硬阻断并逐项确认一般告警、离线设备、人工基线与终端离线风险。
6. 填写值班人员和备注后完成交接。服务端状态已变化时会拒绝旧检查单，必须重新检查。

复位保留告警、审计、配置、终端配对和凭据，不是清库操作。

## 6. 备份、升级与回滚

### 配置备份

- 导出房间、设备、场景、联动、网关、终端和复位策略；
- 明文 Token、PIN、Keystore 密钥不在 JSON 中；
- 恢复前预览差异，配置版本冲突时逐项选择本地或服务端版本。

### 数据库快照

- 主屏每天使用 SQLite `VACUUM INTO` 创建一致性快照并保留最近 7 份；
- 快照必须通过独立只读连接 `PRAGMA quick_check`，显示 schema、SHA-256 与容量余量；
- 正式数据域为审计、告警、命令和场景执行；系统默认不自动删除；
- 快照原子导出到 `Download/SmartLab` 后再复制到受控介质；
- 运行中不提供数据库覆盖恢复。灾难恢复必须停止 EdgeCore、保留损坏副本、检查完整性和 schema，再由交付工程师执行。

### APK 与 UI

- APK 升级必须 versionCode 递增且使用同一交付签名；
- 签名 UI 更新使用 Ed25519 公钥验签，逐文件校验 SHA-256 后原子激活；
- 副屏从主屏同步同一签名 UI 版本；
- 回滚先使用后台 UI 回滚；APK 回滚需按安装生命周期脚本验证，不得覆盖数据库后强行降级。

## 7. 常见故障

| 现象                    | 判断与处理                                                                                     |
| ----------------------- | ---------------------------------------------------------------------------------------------- |
| HA 可控、Web/APK 不可控 | 检查页面是否“正式”、EdgeCore 健康、终端 Bearer、设备 capability 和命令终态；不要改用 Mock 掩盖 |
| 网关在线、灯离线        | 在 HA 查看实体是否 `unavailable/unknown`，恢复后重启适配器或 EdgeCore并等待首个权威状态        |
| 副屏显示离线缓存        | 确认主屏 8787 可达、控制域证明通过、配对未撤销、两屏时间和版本正常                             |
| 物理屏离线而 Web 在线   | 两者是不同终端，按各自心跳统计，属于可能的真实状态                                             |
| 控制一直 pending        | 查网关/HA 延迟、实体回传和命令审计；不得手工改为成功                                           |
| 色温或灯效不可点        | 目标实体未上报对应 capability；先核对 HA `supported_color_modes`、范围和 `effect_list`         |
| 配置保存冲突            | 查看三方差异；逐项合并或明确放弃本地修改，不能刷新覆盖                                         |
| 后台自动锁定            | 重新输入 PIN；未保存草稿只在受限本机加密存储中恢复，不会自动保存                               |
| 主屏夜间整体变暗        | 当前正式版本没有定时夜间遮罩；强制刷新/重启 APK，核对是否仍加载旧签名 UI 资源                  |

## 8. 安全与网络边界

- 8787 当前是受控私网 HTTP，不能抵御同 VLAN 主动实时中继；使用受信 VLAN、防火墙和终端白名单；
- 不在截图、文档、设备名、URL、浏览器存储或日志中放 PIN、HA Token、DID/MAC 对照表；
- 门锁主动开锁、语音、厂商云 API 和非官方网关代理必须单独授权并实机验证；
- 未获许可不得分发 `openmiio_agent` 或复制小米官方 HA 集成代码；
- 第二套实训台必须使用独立 Keystore 凭据和控制域。

## 9. 现场验收清单

1. 两屏型号、Android、分辨率、触控、网络、摄像头、麦克风和扬声器逐项记录；
2. 主屏/副屏安装、升级、重启、Kiosk、断线恢复、界面切换通过；
3. 单设备开关、连续值、枚举、外部状态回传和失败/超时提示通过；
4. 回家、离家、夜间、观影逐动作验证 completed/partial/failed；
5. 自动联动、告警确认/恢复、复位和交接留有审计；
6. 第二套实训台不串台；
7. 记录每个 SKU、内部 model、固件、实体、能力和结果；
8. 对 RS-485、1424×280、副屏采购差异、门锁容量、R11 和语音形成缺口说明。
