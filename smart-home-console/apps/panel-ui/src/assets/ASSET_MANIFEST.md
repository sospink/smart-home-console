## 后续素材规则

1. 禁止在正式界面中引用网络图片 URL；所有资源经过文件名、来源、许可证、用途登记后入库。
2. 场景照片建议统一输出为 WebP，主屏 1600×900、副屏 1024×600，单张目标小于 250KB。
3. 实物设备图到货后采用统一 45° 或正面角度拍摄，背景去除，导出透明 WebP；禁止直接抓取电商图用于商业交付。
4. 生成式素材需要保存最终提示词、生成日期、模型和人工审查记录。
5. 品牌 Logo、小米/米家商标和产品宣传图在取得书面许可前不得作为系统品牌素材。

## 2026-07-22 设备素材补齐说明

- 当前会话未提供图像生成工具，因此未伪造“AI 已生成”的位图资产；
- 设备页改用原创、无商标的 CSS 矢量产品造型，覆盖采购表中的吸顶灯、筒灯、灯带、开关、窗帘、传感器、门锁、背景音乐和家庭屏；
- 副屏音乐播放使用 `public/audio/` 下 3 段项目内原创合成的本地环境音源，不依赖第三方平台或外网；
- 所有造型随源码离线构建，不含电商图片和互联网热链；到货实拍图按同一组件接口替换即可。

## 2026-07-30 场景素材收口

- `scenes/home.svg`、`away.svg`、`night.svg`、`movie.svg` 统一重绘为无品牌、无文字的原创竖版家居插画；
- 四张场景卡、首页兼容视图和屏保均引用项目原创离线素材，不再包含 Unsplash、电商图或互联网热链；
- 本轮原计划使用 ImageGen 生成位图，但当前环境未暴露内置图像生成工具，因此按技能约束没有切换到需要 API Key 的 CLI 路径，改为可审计的项目原生 SVG；
- 如甲方后续提供定稿视觉素材，可按现有 `sceneArtwork()` 接口替换，不改变布局和交互契约。
